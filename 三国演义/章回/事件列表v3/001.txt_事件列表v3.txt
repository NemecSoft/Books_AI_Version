【标题】三国演义第一回：宴桃园豪杰三结义　斩黄巾英雄首立功

**版本一：详细事件列表**
```
【详细事件列表】
1. 天下大势分久必合、合久必分的背景介绍
2. 汉朝从高祖起义到献帝分为三国的历史变迁
3. 桓帝、灵帝时期宦官专权导致天下大乱
4. 建宁二年各种不祥之兆出现（青蛇、地震、冰雹等）
5. 张角三兄弟获得《太平要术》天书，创立太平道
6. 张角散施符水治病，自称"大贤良师"，聚集信徒
7. 张角建立三十六方组织，准备起义
8. 朝廷发现张角阴谋，斩杀马元义，逮捕封谞
9. 张角提前起义，自称"天公将军"，张宝、张梁分别称"地公将军"、"人公将军"
10. 黄巾军四五十万人造反，官军抵挡不住
11. 朝廷派遣卢植、皇甫嵩、朱儁三路兵马讨伐
12. 幽州太守刘焉招募义兵抵抗黄巾军
13. 刘备在涿县看到招军榜文而叹息
14. 张飞与刘备相遇，两人结为朋友
15. 关羽到店中投军，与刘备、张飞相识
16. 三人在张飞庄上商议大事，决定桃园结义
17. 次日在桃园中祭告天地，结为异姓兄弟
18. 中山商人张世平、苏双赠送良马五十匹、金银五百两
19. 三人打造兵器，招募乡勇五百人
20. 刘焉派三人率兵五百迎战黄巾将程远志
21. 张飞刺死邓茂，关羽斩杀程远志，大获全胜
22. 青州太守龚景求援，刘备率兵前往解围
23. 刘备用计三路夹攻，大败黄巾军，解青州之围
24. 刘备前往广宗助战卢植，被派往颍川打探消息
25. 皇甫嵩、朱儁用火攻大破黄巾军
26. 曹操率兵拦截，斩首万余级
27. 刘备在颍川遇到战败的卢植被押送回京
28. 三人救了被张角打败的董卓
29. 董卓因刘备是白身而轻视他们
30. 张飞愤怒要杀董卓，被刘备劝阻
```

**版本二：简要事件列表**
```
【简要事件列表】
1. 汉朝末年天下大乱，张角三兄弟创立太平道准备起义
2. 黄巾起义爆发，四五十万人造反，朝廷派遣大军镇压
3. 刘备、关羽、张飞在涿县相遇，桃园结义成为兄弟
4. 三人打造兵器，招募乡勇，开始征战黄巾军
5. 初战告捷斩杀程远志，又解青州之围立下战功
6. 前往助战卢植，途中救了被张角打败的董卓
7. 董卓轻视刘备是白身，张飞愤怒要杀他，被刘备劝阻
```

**版本三：极简事件列表**
```
【极简事件列表】

3. 三人开始征战黄巾军，初战告捷立下战功
4. 途中救了董卓，但因身份低微被轻视
```
